Tema e Ideia:

  O Travel Explorer é uma aplicação web que permite aos utilizadores pesquisar destinos de viagem e obter informações úteis em tempo real.

  O objetivo é facilitar o planeamento de viagens, apresentando dados relevantes como:

   - Condições meteorológicas atuais
   - Informações do país
   - Imagens do destino

  Além disso, o utilizador pode guardar destinos favoritos e criar uma lista personalizada de viagens.

Funcionalidades

   - Pesquisa de cidades
   - Informação meteorológica em tempo real
   - Dados do país (população, capital, bandeira)
   - Galeria de imagens do destino
   - Guardar destinos favoritos
   - Lista de viagens personalizada

APIs Utilizadas:

  - REST Countries API: Informação detalhada sobre países
  - Unsplash API: Imagens de alta qualidade dos destinos

Tecnologias Utilizadas:

 - HTML5
 - CSS3
 - JavaScript (DOM manipulation)
 - Fetch API
